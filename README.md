# NativeBuilder Hackathon

A small React + Vite demo app used for the NativeBuilder hackathon. It demonstrates voice input, Supabase integration and basic auth state management using React contexts and hooks.

## Features

- Voice input UI component
- Authentication context and demo auth flow
- Supabase client integration (example project)
- Tailwind CSS for styling
